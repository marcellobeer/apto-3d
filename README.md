# Apê 3D · estudo de layout da sala

Modelo 3D navegável do apartamento, feito para testar decoração antes da mudança.

**Abrir:** https://marcellobeer.github.io/apto-3d/

## O que dá para fazer

- Girar, aproximar e entrar na sala (dois cliques no chão).
- Botão **Editar**: abaixa as paredes e mostra a sala de cima para mexer nos móveis.
- Clicar num móvel abre o painel: medidas, rotação, posição, cor por parte e padronagem.
- **Medidas** (ícone de régua) mostra as cotas da sala e as distâncias entre os móveis.
- **Versões salvas** no menu Decoração: salve com um nome, aparece quem salvou, e o ícone de link copia um endereço que abre exatamente aquela versão.

## Precisão

A sala está nas medidas reais levantadas em obra. Cozinha e área de serviço são estimadas a partir de vídeo, com erro possível de 20 a 30 cm.

Estudo de volumes, não projeto executivo.
